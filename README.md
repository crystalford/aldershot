# Aldershot

An AI-assisted video editor for creators making long-form video essays and
commentary — and mining them for shorts — that runs entirely on Cloudflare
(Workers, D1, R2, Workers AI, and a small ffmpeg Container). No separate
backend, no other vendor.

**Live:** `https://aldershot.<your-subdomain>.workers.dev` (see **Deploy**
below). **Design direction / build-order spec:** [Aldershot — From System to
App](https://claude.ai/code/artifact/46662adb-5e52-40d1-af03-5dc3276b8aec) —
the working design doc this session built against; see **Status** below for
what's shipped since it was written and what's still open.

> `docs/design/architecture.md`, `docs/design/product.md`, and
> `docs/research/feasibility.md` describe an earlier, much larger vision for
> this project (an autonomous trend-detection-and-content-generation
> system — "the Radar"). The product actually built and shipped is the
> tool described below instead. Those docs are kept for history, not
> as a current reference — this README is the source of truth for what
> exists today.

## What it does today

**Projects.** Drop in a batch of videos (a base take + commentary, multiple
angles, whatever). Each gets transcribed (Whisper, word-level timing) via a
small ffmpeg Container that extracts and chunks the audio track.

**Edit as text.** The core editing loop is Descript-style: click/drag to
select words in the transcript, Backspace to cut — the cut ripples through
playback and export automatically. Undo/redo, filler-word removal, pause
trimming, search, and a `⌘K` command palette (navigation + every editor
action, always shows the real keyboard shortcut) all work directly against
this transcript.

**AI arrangement.**
- **Auto-arrange** — reads every transcript in a project and proposes a
  full long-form cut (a cold open of the punchiest hooks, then the rest in
  narrative order).
- **Direct the edit** — same thing, but driven by a plain-language
  instruction ("a video about how the host keeps interrupting the guest")
  instead of a generic best-cut.
- **Suggested edits** — finds callbacks/contrasts/themes connecting
  moments that are far apart in the transcript, each with a one-line
  rationale grounded in a real quoted moment (never an invented timestamp).
- **Bridges** — once a cut exists, finds the gaps between clips that need
  connective narration, writes a script for each, and records straight
  into the gap (webcam or voice-only) through the same
  upload→transcribe pipeline as any other clip.
- Every suggestion (Cut segment, Suggested Edit, Short) hover-highlights
  the exact words it's about directly in the transcript, and can be
  dismissed — nothing generated by an AI feature sits there forever with
  no way to say no to it.

**Shorts.** Finds self-contained 15–60s moments across a project, ranked.
"Produce" renders a short **publish-ready**, not just a raw trim: centered
9:16 reframe + burned-in karaoke-style captions (word-by-word highlight,
generated from the same Whisper timestamps), entirely in the browser via
ffmpeg.wasm.

**Archive.** A persistent, cross-project library of saved clips — save a
selection from any project's transcript, tag it, search it later.
**Discover** finds new candidates across every project's transcripts at
once. **Compose** drafts a full video essay directly from the archive via
a plain-language instruction — the model only ever picks and orders real
clip ids, never invents a timestamp. **Reaction clips** suggests an
existing archived clip that lands as a cutaway right after a line you
select.

**Visual tagging.** Keyframes get captioned and OCR'd (Moondream, Workers
AI) whenever a clip is saved, so clips and the archive search surface
what's *on screen*, not just what's said.

**Enhance audio.** One-click denoise + EQ + leveling + loudness
normalization (ffmpeg in the Container: RNNoise denoise, presence EQ,
compression, two-pass-equivalent `loudnorm` to a podcast target, a
limiter) — a self-hosted approximation of Descript's Studio Sound
classical-DSP layer. Non-destructive: previews original vs. enhanced
side by side before anything changes.

**Version history.** Every Cut/Timeline save archives whatever it's about
to overwrite first — auto-arrange, direct edit, manual saves, restoring a
past version itself — so a bad AI run or a bad drag-reorder session is
always recoverable, not just undoable in the current tab.

**Export.** The arranged long-form cut and every short render **in the
browser** (ffmpeg.wasm) — no server render needed to ship.

**No accounts.** Aldershot currently has no login — everything is one
shared workspace. (A full auth + per-account retrofit was built and
verified working in this session, then deliberately reverted at the
founder's request to stay focused on the product before launch is
imminent — see git history around commit `fde2ed0` / its revert
`419b69e` if that work needs to be resumed later. Nothing about the
current schema blocks re-adding it.)

## How it's built

- **Cloudflare Workers + Hono** — the entire API (`src/index.ts`), no
  separate backend.
- **D1** — projects, videos, clips, visual tags (`src/db.ts`,
  `src/clips.ts`, `src/visualtags.ts`; lazily-created schema, no migration
  runner — `migrations/*.sql` are checked-in mirrors of the `ensure*Schema`
  functions that actually run, for reference against prod D1).
- **R2** — every video, transcript, timeline, and rendered asset
  (`src/keys.ts` is the canonical object-key layout).
- **Workers AI** — Whisper (transcription), an LLM (arrange/suggest/
  shorts/bridges/compose, in `src/pipeline/reason.ts`), Moondream (visual
  tagging).
- **Cloudflare Container** (`container/`, Debian + ffmpeg + Node) — the
  one piece of server-side compute, used only for audio extraction
  (transcription) and audio enhancement. Everything else (cutting,
  captioning, reframing, export) renders **client-side** via ffmpeg.wasm
  (`public/render.js`), so the app deploys and runs without Containers
  enabled at all — those specific features just 501 until Workers Paid +
  Containers are turned on.
- **Vanilla JS frontend** (`public/app.js`, no framework/build step) —
  Newsreader italic (headers/titles/editorial voice) + IBM Plex Sans (UI
  chrome) + IBM Plex Mono (metadata/timestamps), self-hosted woff2s in
  `public/fonts/`. Violet (`#8a7bd4`) is the one settled accent — no other
  direction is current.

### API surface

Projects/videos: `POST /api/projects` · `GET /api/projects[/:id]` ·
`POST /api/projects/:id/videos` (+ `/presign`, `/confirm` for large
direct-to-R2 uploads) · `POST /api/videos/:id/transcribe[-remote]` ·
`PUT /api/videos/:id/transcript` · `GET /api/media/*` (range-aware
playback).

Arrangement: `PUT /api/projects/:id/timeline` · `POST
/api/projects/:id/arrange` · `POST /api/projects/:id/direct` · `POST
/api/projects/:id/suggest-edits` · `POST /api/projects/:id/shorts` ·
`POST /api/projects/:id/bridges` · `GET /api/projects/:id/history` +
`POST /api/projects/:id/history/:timestamp/restore`.

Archive: `POST /api/clips` · `GET /api/clips[/:id]` · `PATCH
/api/clips/:id` · `DELETE /api/clips/:id` · `GET /api/clips/tags` ·
`POST /api/clips/discover` · `POST /api/clips/compose` · `POST
/api/projects/:id/reaction-clip` · `POST /api/clips/:id/visual-tags`.

Audio: `POST /api/videos/:id/enhance-audio` · `POST
/api/videos/:id/apply-enhanced-audio`.

## Deploy (needs your Cloudflare account)

```bash
npm install
npx wrangler login
npx wrangler r2 bucket create aldershot-media
npx wrangler d1 create aldershot            # paste the returned id into wrangler.jsonc (replace "TODO")
npm run deploy                              # -> workers.dev URL
```

Tables are created lazily by each `ensure*Schema()` on first request — no
separate migration step needed for a fresh deploy. The GitHub Actions
workflow (`.github/workflows/deploy.yml`) does the same thing on every
push to this branch, given `CLOUDFLARE_API_TOKEN` + `CLOUDFLARE_ACCOUNT_ID`
repo secrets (and optionally `R2_ACCESS_KEY_ID`/`R2_SECRET_ACCESS_KEY` for
large direct-to-R2 uploads).

Containers (audio extraction + Enhance Audio) need the account on
**Workers Paid** with Containers enabled — the rest of the app works
without it; those two features 501 until it's on.

## Local dev

```bash
npm run dev         # wrangler dev — Workers AI calls still hit your live account
npm run typecheck   # tsc --noEmit — run after every change
```

Containers can't run in most sandboxed/local environments without Docker;
`wrangler dev --enable-containers=false` runs everything else.
